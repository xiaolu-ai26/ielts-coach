# 各科记录与统一复盘

本模块由Skill统一收尾调用，不要求用户主动记得说“输出复盘”。各科负责根据真实作答分析问题；本模块负责本次整理、持续记录、复测和跨科汇总。词汇是独立学习模块，不算模考第五科。

## 一、一次练习结束时主动询问

完成用户请求的练习批次后，先给一句本次结果，随后主动询问：

“这次要保存一份复盘，并准备下次复测吗？可以一起准备、只保存复盘，或者这次先不输出。”

该问题每个练习批次问一次，不逐题打断。阅读先处理错题和已提出的存疑题，回述结果如未取得则标待完成；用户说今天结束/没时间继续时可直接询问是否保存进度，不要求完成所有阶段才允许输出。纯查一个词、只打印空表等没有实际作答的任务，不编错误或强制复盘。

用户已要求自动保存，或同一会话已明确选择，则照既有偏好执行，不重复问保存权限；仍可简短询问是否准备复测。没有回复不视为同意保存或准备新练习；当前对话内已观察到的内容可继续使用，但不得声称已持久保存。

“先不输出”时尊重选择，不在后台另建报告或定时提醒；无需因此删除用户既有记录。用户只要复盘就不额外生成试卷。准备下次复测不等于设置日历、通知或自动唤醒。

## 二、记录分科，复盘有三个范围

1. **本次复盘**：只包含本次实际练过的模块与任务。一篇阅读、50个词、一道写作任务都能独立复盘，不等其他科齐全。
2. **累计分科复盘**：从历次记录中看同科问题是否重复、是否经过提示、复测是否成功。词汇、听力、阅读、写作、口语各自保留可区分的记录。
3. **跨科汇总**：周复盘或用户指定阶段汇总，指出共同问题、证据及下阶段任务；没有练过的科目记无新数据/未练，不记0分。完整模考汇总另按模考身份和条件核对，不能把最近四条不同练习拼成一个考试总分。

这些是同一批记录的不同呈现，不把原答复制到多个互不一致的错题库。沿用progress.md定义的学习目录：sessions记录原始练习与复测，errors.md作为累计索引引用记录ID；生成的Markdown报告、CSV和PDF是输出，不替代原始记录。既有文件结构可沿用，不为格式统一自动迁移或覆盖用户资料。

## 三、每条记录与各科差异

共用字段：attempt_id、module、日期、材料/页/题号或词条、原始作答或可访问文件、参考答案/评分依据、帮助条件、用户原思路（未知不填）、已确认错因/待验证假设、修正动作、状态、复测关联ID。

- 词汇：原词及当前义项、用户中文、基础版/提示版、识义/听辨/拼写各自证据；只做英译中不能补出英文拼写成绩。既有打印生成流程原样调用。
- 阅读：原答、答案来源、定位证据、题干对应、错因与回述原话/注明摘要。猜对或存疑与答错分开。
- 听力：实际听到或填出的内容、可靠答案、可确认的音频位置、是否重播/看文本、辨音与理解的检查结果。没有音频不编时间戳或听辨结果。
- 写作：题目、原稿与修订稿分别保存、四维反馈证据、重复问题、独立/辅导条件；不把AI改稿作为学生原始成绩。
- 口语：题目、原话/录音或转写位置、是否有声音证据、反馈维度、重答和提示条件；不从纯文字补发音分。

保存观察到的事实，不把示例、模拟作答或演示错误混入真实学员记录。重复问题以issue_id关联不同attempt；每次原答仍独立保留。问题相似不代表同一错因，归并前核对证据，不跨科过度推断“词汇差”等整体能力结论。

## 四、输出和下次复测

用户选择输出后，默认生成本次Markdown复盘；需要表格时导出累计CSV，需要纸面复习时生成PDF。不要每次都强制生成所有格式。AI可在询问时说明本次建议，例如“阅读复盘和原题式无答案复测页”。

PDF练习版保留原题型、题号、题干、选项及必要答题要求，只留原题所需空格或选项作答位置，不增加依据栏、解释问答或额外回述任务；原文可附后或给材料位置。正确答案、译文、括号标注、解析与其他提示放在独立答案版。词汇继续采用已定四列格式；同批新词与昨日复习分别标记。没有文件能力时在对话中交付可复制文本，不能称文件已生成。

状态：待分析 → 已讲解 → 待独立重做 → 本次独立通过 → 待延后复习；有提示通过单列。隔日又错保留新记录，不能覆盖旧成绩。词汇默认次日先复习昨天那批约50个；其他模块按问题与时间安排，不把间隔当固定教学保证。

下次用户回来时，读取已有记录，主动提示：“上次还有……待复测，今天先检查一下，还是直接做你今天的任务？”用户明确说先做新任务则直接执行，不以未复测为通关门槛。不能在用户不在场时自行完成test或生成成功记录。

## 五、完整模考与分次完成

明确是一套模考时分配共同mock_id，并登记考试类型、试卷身份、四科状态、各科日期和用时、原始/估计成绩来源及帮助条件。可分次完成并续接，但标注“分次完成”，不要冒称一次连续全真模拟。

只做了听读：先输出听读复盘；写作、口语标未完成，暂不算四科总分。后续补做同一计划里的写说，可按mock_id关联后汇总。词汇练习不计入模考总分。

不同日期不同材料的日常训练可合成周复盘，但不叫同一套模考。只有四科证据与适用评分条件齐全才讨论总分；写说含AI估分时总分也是训练估计。缺声学证据的口语不能靠文字补一个完整分数凑齐。

## 六、简例

- 今天只练阅读：本次阅读复盘 → 关联阅读累计记录 → 询问保存和下次回述，不催用户补听写说。
- 今天背词并做阅读：同次报告分词汇与阅读两节，两科各记自己的表现；共同词义问题有两处证据才关联。
- 分三天做同一套模考：各次先复盘，沿同一mock_id累计；最后一次材料齐全后主动询问是否输出整套总结。
- 一周只练听读：周总结仅分析听读及已有词汇证据，写说写未练，不计算虚假的整体分数。
