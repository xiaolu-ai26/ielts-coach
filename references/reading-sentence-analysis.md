# 长难句与段落：解释为什么影响答案

选用户标记的句子、答案证据句或造成误解的上下文。不要强制按长度阈值给全文所有句子做语法标签；用户需要全文精读时再扩展。

## 讲到能理解，不只贴标签

用户要求详细讲解或表示没听懂时，题干和证据句都要拆。默认在原句中直接用括号和紧邻标签标注成分，保留原词序和整句连续呈现，不人为按成分分行；不能让用户在原句与一张术语表之间来回找。表格只作用户需要时的补充，不作主要呈现。不要求用户先熟悉术语才能继续。

固定呈现顺序：未改动原句 → 原句内括号标注版 → 按同一顺序分块说人话 → 本题答案所依赖的关系。标签是AI添加，不属于原文。嵌套从句用外层括号标清起止；先标外层，需要细讲时另给一整句内部细标版，避免同一句堆满多层标签；指代/修饰对象紧邻写明。正常输出无需给每个单词贴标签。

只提取主干或缩短句子时注明“主干摘取/简化改写”，不得把丢掉修饰或改词后的句子称为完整原句。印刷时可辅以颜色，但黑白打印也必须靠括号、标签看清层级。

原句内标注示范（AI自拟，非教材或真题原文）：

原句：Although the library added two reading rooms, noise remained a problem.

> Although（尽管） [the library]（从句主语：图书馆） [added]（从句谓语：增设） [two reading rooms]（从句宾语：两间阅览室）, [noise]（主句主语：噪音） [remained]（系动词：仍然是） [a problem]（表语：一个问题）.

白话解释：尽管图书馆增设了两间阅览室，噪音仍然是问题。点明“采取了措施”不等于“原问题已经解决”；在具体题目里还要结合题干核对，不能只凭出现added就推断问题已消除。

- 主语：这句话主要在说谁或什么；可能是一整段动名词/从句，不一定是人。
- 谓语：关于主语说了什么动作或状态；被动结构中的主语是动作承受者。
- 宾语：动作涉及的对象；不能把所有动作后的短语都叫宾语。
- 系动词与表语：连接主语与其身份、性质、状态或内容。His idea was to…是主系表，不把不定式表语硬叫宾语。
- 定语/定语从句：说明前面名词是哪一个、什么样；须具体指出修饰对象。
- 状语/状语从句：补充时间、地点、原因、条件、让步等关系；拆出主句的实际结论。
- 形式宾语it：先占据句子中的宾语位置，后面的不定式说明具体事情；如make it possible to…，要解释possible是宾语补足语，不能把it误认成铁路。

每个术语紧跟本句中的作用和白话意思，不列脱离题目的语法大全。可用一个贴合的短比喻，如“给名词贴身份标签”“搬家任务的旧住址与新住址”，但要明确比喻是解释，不是原文事实或额外证据；讲完回到原句。不能用比喻掩盖指代、逻辑范围或语法分析不确定性。

读者要求答案确认时，直接给已核的书名、Test/Passage、题号和书后答案页；说明答案表来自材料、具体讲解由AI分析，不能把自己写的解析称为书后官方详解。无答案页就坦白未核，不以语气肯定代替证据。

## 操作顺序

1. **保留原句**：给页/段/句位置，不能把改写句冒充原文。必要上下文一起看，尤其指代与转折。
2. **找谓语与主干**：识别主句的主语、谓语及必要宾语/补语；区分真正谓语与分词/不定式。原句中删修饰得到的片段标“主干”，为易懂而补词重写的句子另标“简化改写”。
3. **划分修饰**：在连续原句里用括号显示从句、非谓语、介词短语、插入语/同位语的范围。每部分写清“修饰哪个词/说明哪个动作”，而不只贴定语从句标签。
4. **查指代**：解释this/that/which/they/it指向名词还是前面整件事，指代有歧义时列依据与未确定处，不能自动选最近名词。
5. **查逻辑范围**：谁否定谁、比较两者是什么、条件和让步约束什么、因果方向、数量和程度。简化时不能丢not/only/some等改变真值的成分。
6. **分块理解再整句翻译**：逐块说清再连起来，不先贴一段流畅翻译掩盖语法关系。多个分析合理时采用能解释题目且有证据的分析，不装作只有一种术语体系。
7. **接回答题**：明确这一结构怎样支持答案或排除用户误选。语法讲解到能回答当前问题即可，想继续学再扩展。
8. **让用户回述**：收起分析，让用户指认主干、用中文说句意或指出限制关系，依据真实回答判断，不要求背语法名称。

## 按用户实际卡点调节帮助

先解释已识别的问题，不把每题扩成全套语法课程。用户仍不懂时，分别检查是不认识词、没认出句子成分、接错修饰对象，还是理解句意却不懂题干对应。依真实回答加讲，不凭用户学历或一个错误猜英语水平。

理解检查时撤掉成分标签、译文、强调和比喻，只保留原文与题干；让用户自己说谁做什么、哪块修饰谁、哪处决定答案。若答不出，可只提示一层结构，再等待，不马上重新贴整份解析。使用过提示的回述单独记录，不能与独立解释混淆。

语法标注与官方答案是不同层面的判断：书后答案核对不证明AI每个语法标签都正确。对多种合理句法解释、指代歧义和OCR不确定处明说，不为了得到预设答案强行归类。

## 自拟演示（非真题）

原句：Although the method that the researchers tested reduced costs, it did not improve accuracy.

- 主句：it did not improve accuracy；不要删掉not。it在这里指the method。
- Although引导让步部分：the method … reduced costs。
- that the researchers tested修饰method，说明研究人员测试的是哪个方法；tested不是整个句子的唯一主句谓语。
- 整句：尽管研究人员测试的那个方法降低了成本，它并没有提高准确性。
- 若题目声称“该方法同时降低成本并提高准确性”，第二项与原文明示的否定矛盾。不能看到reduced costs匹配就忽略后半句。
- 回述时仅给原句与题干，问用户“哪部分决定你的判断，为什么？”，不先重贴否定解释。

## 段落结构补充

当错因涉及主旨/定位时，以实际语句说明段落在引入问题、列证据、举例、比较、转折、解释原因或总结什么。不是每段都具备全部功能。只见局部材料时不给全篇结构图；补齐全文后才做段意和段间关系表。
