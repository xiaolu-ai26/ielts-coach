# 自动生成两版词汇PDF

用户要求“按这本资料前50词生成可打印词表”时，直接执行本流程，不只交教程或空模板。需要宿主可读取材料、运行Python和写文件；只有手机纯聊天时不能承诺直接运行脚本。

1. 读取用户材料，按指定范围提取编号和英文主词/短语，保留原序与实际来源页码。主词与同替列不混算；扫描件需OCR和原页核对。已完成材料提取时复用核对结果。
2. 为每词写一条很短的英文搭配/自拟语境提示，不写中文释义。提示对应当前义项，不把教材印刷或词性错误机械复制。提示不是教材原句，来源说明中标明AI补充。
3. 保存JSON到本次输出目录（不写入Skill本体），格式如下。id唯一，顺序以items数组为准，word和hint单行。

```json
{
  "title": "阅读考点词 01-50",
  "source": "来源：用户阅读PDF第1-3页；提示为AI补充搭配/短句。",
  "items": [
    {"id": 1, "word": "resemble", "hint": "resemble a leaf"},
    {"id": 2, "word": "recognize", "hint": "recognize her voice"}
  ]
}
```

4. 用当前环境Python执行，需reportlab；依赖缺失时使用可用文档运行时或按环境规则安装，不声称已生成。脚本路径相对本Skill目录。

```bash
python3 scripts/make_vocab_sheets.py --input /path/to/words.json --output-dir /path/to/output
```

输出 vocabulary-basic.pdf、vocabulary-hints.pdf。两版词序、位置相同，每50词一页A4。四列英文/中文留空/英文/中文留空，左1–25条、右26–50条；不足50条保留其余空白。超过50条自动分页。输出目录内同名文件会被替换，默认选本次任务专用目录，勿覆盖用户无关文件。

5. 脚本遇到过长词或提示会报错，不静默裁切。提示过长时改写得更短并重跑；长词不可随意截断，需调整渲染布局。不要为省页数把字缩到难辨认。
6. 核对词数、原词序、页数、两版一致、中文栏空白、没有遗漏或多带同替；用PDF渲染器出预览并查看边界与字体。交付PDF及需要的预览，说明实际完成的是文件生成而非已经打印或验证学习效果。
