# 资料准备与输入检查

## 最小起步材料

一套对应考试类型的可靠练习材料（题目、答案；听力另需配套音频与文本）、当前官方评分说明、一个存原稿和记录的目录即可开始。没有购书预算先用官方免费样题，不强制购买某品牌会员。资料来源链接见 sources.md。

不要把用户的“官方电子书”自动认定为某册剑桥雅思。请用封面、版权页或文件名确认名称、版本、A/G 和配套音频；用户已提供时直接读。使用合法取得的材料，不引导找盗版合集；分享 Skill 只附方法和官方入口，不打包整本付费教材。

## 导入顺序

1. 先列材料清单与缺项，按科目和版本分组。已知路径直接读，不让用户反复上传。
2. 每次只取本次题组及其必要上下文。PDF 图片看不清先指出页码和位置，不能凭相似真题补全。需要 OCR 时保留原图，重点校对数字、否定词、题号和字数限制。
3. 把题目与答案分开放。训练开始前不展示答案、解析或音频文本；用户要求讲解已做题则可以一起读。
4. 登记实际来源和路径，确认题目、音频、答案的 Test 编号一致。
5. 将未见材料保留一部分用于验证，避免全部先精读再“模考”。

材料表字段：`material_id | 科目 | A/G | 标题/版本 | Test/页码/题号 | 原文件或链接 | 配套答案/音频/文本 | 已做状态 | 收集日期 | 来源类型`。
来源类型区分官方样题、授权出版材料、第三方整理、学习者回忆、自拟练习。第三方“当季”题库记录原声称，不自动认可。

## 三种工具环境

- 只有手机聊天 App：分次发题目截图/正文，语音陪练使用完整复制指令，结束时要求生成续接摘要；用户把摘要存到自己的笔记。
- 本地 Agent 能读写文件：保留原始材料与练习记录，按材料 ID 检索；没有音频理解工具就让用户本地播放，不假装已经听完。
- 外部备考平台：用户已经选择且连接可用时才接入。先确认账号权限、实际可导出字段及费用；正式作答和提交依平台接口，不猜内部题库。没有连接照样使用文件/复制文本流程。

“数据文件保存在本地”不等于使用云模型时原文从不发送。需要云模型分析的内容会进入对应服务的处理流程；上传范围遵循用户当次选择，不复制无关个人资料。

## 旧视频和资源筛选

先判断它解决什么具体问题，能否回到当前官方评分要求，有没有完整例题及纠错过程。只留下本周弱项相关的 1–2 项资源，练后再换。粉丝数、播放量、GitHub 星数均不证明提分效果。

某作者、题库会员、课程版本或平台入口的信息未经当前核验时，不给最新价格与购买建议。用户提供历史作者名单可以作为检索线索，不能把搜到的新视频写成用户当年亲测过的同一条。
