# 按需求或顺序学习

## 直接进入

用户给了明确任务就进入相应模块，已有材料直接读。不要为了路由而展示长菜单。

| 意图或输入 | 入口 | 不要先强加 |
|---|---|---|
| 单词表、打印A4、背词、词汇复习 | vocabulary.md | 阅读整篇或水平诊断 |
| 做完阅读、错题号、为什么选错、长难句 | reading.md | 完整个人档案、先背完单词 |
| 音频、听力错题、日常泛听 | listening.md | 阅读模块或复杂诊断表 |
| 原题和作文 | writing.md | 先跑其他科 |
| 口语或语音陪练 | speaking.md | 先生成范文 |
| 不知道怎么准备、制定计划 | intake-planning.md | 全量资料导入 |
| 周复盘、模考、考前考后 | progress.md | 强制开始新一轮练习 |

“同义替换”有文章题目时先在阅读中解释对应关系；只给词表时进词汇。一次包含多个需求时，按用户优先级处理，有必要才问先做哪个。阅读结束导出词表时调用既有词汇流程，不复制、覆盖或改写词汇规范。

## 按顺序学习

用户说“从头带我学”“按顺序来”才启用。先用最少信息确定目标和可用时间，再给一个可调整的学习顺序：资料与基线 → 词汇 → 阅读 → 听力 → 写作 → 口语 → 周复盘/模考。词汇到口语是循环的模块顺序，不是要求学完全部词汇才接触其他科，也不要求一天完成所有模块。

每次只展开当前任务。完成后展示一句当前结果和下一模块的具体入口；由用户选择继续、停下或跳转，不能把未作答的练习标已完成。用户有自己的顺序就沿用。

记录：当前模式（按需/顺序）、当前模块、当前任务与题号、已完成动作、未完成动作、可访问材料路径、下一模块。相同模块跨会话续接时带回未完成原题与用户原答，不能仅凭摘要重建原文。

用户中途只想问一题，先回答这一题，再按其意愿回到原进度。模块路由不自动授权上传、提醒、报名或跨App操作。
