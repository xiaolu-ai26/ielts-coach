# 阅读题型的具体分析动作

以完整题面和当前官方格式为准。按当前题型读取，不一次教完所有规则。

## 句子、摘要、笔记、表格、流程与图示填空

1. 读答题要求：允许几个词/数字；从原文取词还是从给定选项选；答题卡要词还是选项字母。例句改写训练不等于原题可随意改词形。
2. 读完整题干或摘要上下文，不能只看空格左右两词。列主干、空格承担的成分、前后冠词/介词/谓语等限制；词性预测只作候选范围。一个空可能需要短语，a/an后也不必立即就是单个名词，不能用机械口诀定答案。
3. 说明内容上需要什么：对象、特征、过程、原因、结果、数量等；与原文的叙述对象和范围对应。
4. 定位相关段落，比较原文和题干的主被动、词形/词性改写、指代、近义表达与逻辑。句子填空按题型可用顺序帮助定位；摘要/笔记/表格/流程等不一律假定同序。
5. 将候选逐项代回，分别验证语法是否成立、意思是否有原文依据、是否符合抽词/选项和字数限制。仅语法成立不能选定。
6. 对原文取词题保留题面要求的原文形式，若候选必须被随意改写才通顺，先重查定位、抽取范围及题干，不先造新词填上。检查答案表允许的变体，不自造唯一答案。
7. 解释用户填法的具体失败点：多带修饰词超限、单复数抄错、抽错同段名词、忽略转折等。不能仅因名词不匹配就断言用户没背词。

## True / False / Not Given 与 Yes / No / Not Given

拆陈述为主体、谓语、对象和限定（数量、频率、比较、时间、因果）。区分事实信息与作者观点，沿题面使用T/F或Y/N。

给出原文支持、矛盾或缺少哪项信息。支持/矛盾可以通过明确的语义关系成立，不要求逐字出现反义词；不能用外部常识补证据。“some”通常只表存在部分，不能无条件推成“并非全部”。话题提到但具体比较未说明仍可能信息不足，不能见关键词就判True。

如判Not Given，说明缺的是哪项关系，而不是只说“没找到”；材料残缺先补范围，不能用一个截断句证明全文没说。用户把False与NG混淆时，用当前证据区分“有反证”与“缺信息”。

## 标题匹配

先概括整段主要在做什么，再比较标题覆盖范围。检查选项是否只是举例、背景、另段内容，或把对象/范围扩大了。引用足以支撑主旨的原句；不能强制先做标题题，也不能把主旨固定为首句或首尾句交集。

错题讲解按五步展开：①用用户原标记和解释确认其选项依据；②将全段按实际功能概括为主题、展开、例子、转折/结论，不要求都有；③写一句不带选项措辞的段意；④逐个比较有关标题的主体、范围和中心观点，给“覆盖主旨/只是细节/范围过大/别段主题/无依据”等理由；⑤回到用户误选，解释为何抓到了真细节却没概括全段。可用“章名与其中一张照片说明”的类比，但仍须给原段证据。

标题能概括多个例子的共同用途，比只复述其中一个故事更合适；段首可能在承上启下，段尾可能是例子，不能只按位置裁定主旨。指出证据如何支持概括，而不是只翻译标题和报编号。

用户指定的书中没有此题型时如实说明，不把信息匹配改名为标题匹配。使用真实段落另拟标题可作演示，但必须在题面和答案附近写明“AI自拟标题匹配，非原书题目，无书后答案”；不得冒用原题号或书后答案。要核验官方题型表现，应另用确有标题原题及答案的材料。

## 信息、人物/特征匹配与句尾匹配

信息匹配定位特定信息而非整段主旨；检查选项能否重复使用。人物/特征匹配区分谁提出、谁反对、谁被引用，核对代词和报告动词。句尾匹配同时验证句法连接和意思，不因为能拼成通顺句就选；更多选项意味着需要排除，不能凭未使用选项硬凑。

信息匹配逐项拆要求：信息类型（态度/例子/数字/解释/比较）、讨论对象、限定条件（正负、时代、特定地点等）。找到段落后逐项核对；只看到数字不能证明是所需环境效益数字。用户误选另一段时，将两个段落的实际信息并排解释：如“人们的负面态度”与“建筑的客观缺点”虽都负面却不是同一任务。段落整体主旨不同也可能包含所需细节，因此不能拿标题匹配标准排除信息匹配答案。

## 选择题与简答题

选择题对每个相关选项核查对象、程度、因果、范围和作者立场，指出误选为什么“看着像”：有相同关键词但说了别的事、原文事实被换了主语、例子被扩成结论等。多选核对要求选几项。

完整选择题示范须逐个检查所有选项，不只解释正确项。每项按“选项断言 → 原文证据或缺口 → 支持/矛盾/未提及 → 是否选择”输出；无证据不等于断言在现实中一定错误。多选先逐项验真，再确认数量及书后允许的答案顺序，不给两个答案虚构优先次序。

特别检查：材料变新不等于更不耐用；提供电力不等于居民耗电减少；安装某技术不等于开展该技术研究；设施更多不一定是为了原题所说的特定人群。此类判断应回具体文章核实，不能当成永远错误的选项模板。

简答题先明确疑问词与所需信息，再定位和按题面抽取，核对字数/数字限制；不能从常识答题。所有题型无可靠答案时，将AI推理与正式核分分开。

## 核验入口

[IELTS Academic Reading 官方格式](https://www.ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-reading)；2026-10-21核对了句子填空与摘要类填空的取词及顺序差异。不同考试类型或规则变化时回官方核实。

干扰项含一个积极效果而原文描述另一个效果时，不自动互斥：例如原文强调体育之外的公共服务，并不能单独证明观赛设施绝无改善；须判断选项声称的具体效果有没有证据。不得给选项补上only/exclusively后再排除。分析内容时可称“关键活动/结果”，只有实际句法角色确为动词谓语时才标为谓语。
