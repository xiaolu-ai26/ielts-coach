# 阅读复盘记录模板

按需生成，不要求用户先填完才能解析。纸面材料和解析分开；用户自己的标记照原样保留。

打印作答区按题量紧凑排版：三道短题通常合并到一页，能清晰放下时使用半页；严格保留原题型、原题号、题干、选项和必要答题要求，只留原题需要的作答位置，不增加依据栏或解释问答，不默认一题一页。需要长篇解释可以口头对AI说或另纸补写。原文附页与纯作答页可分别导出，方便已有教材的用户只打印作答区。

## 题型专用补充（只用当前题型）

- 标题匹配：全段展开顺序 → 不借选项措辞概括段意 → 正确标题覆盖哪些主要内容 → 误选是真细节、过大范围、别段主题还是无证据信息。自拟标题必须与真实题号和官方答案分开标识。
- 信息匹配：信息类型、对象、限定条件 → 实际出现位置 → 每个条件如何满足 → 原误选段落缺哪个条件。可重复字母按题面，不用“已用过”排除。
- 选择题：每一项的完整断言 → 原文依据/信息缺口 → 支持、矛盾或未提及 → 是否选择。多选确认数量和答案顺序规则。没有证据的选项不扩大成现实中一定错误。

## 对话回述（不印入默认复测题面）

打印复测只保留原题形式；以下问题留在用户作答后的AI对话中使用，不自动加进试卷。需要时给原文和题干的可访问位置，不重贴答案或定位提示。

1. 这道题具体问什么？
2. 你的依据在哪里？用自己的话解释那段原文。
3. 依据怎样支持你的选择？
4. 原来选错的地方为什么不成立？

用户回答后另存：原始回述、任务理解、证据定位、对应关系、排除理由、提示有无、下一次需补的环节。未回答记“待回述”，不能生成成功记录。

## 可选汇总

本篇相关词汇与出处、值得保留的同替或结构、反复出现的错因。需要纸面词表时转既有词汇模块；不要在本模板改变四列格式。

## 可选新题

只有用户选择加练才添加。题面注明官方/授权材料来源或AI自拟，答案与题目分开；记录新题原答与理由，不用自拟小题组估Band。
